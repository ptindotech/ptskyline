MENDOZER INVESTMENTS - LOGO ASSET PACK
========================================

/svg
  mendozer-icon.svg          - icon mark only, gradient fill, scalable
  mendozer-logo-full.svg     - full lockup (icon + wordmark), scalable

/favicon
  favicon.ico                 - multi-size (16/32/48) for browser tabs
  favicon-16.png / -32.png / -48.png / -192.png / -512.png
  apple-touch-icon.png        - 180x180, for iOS home screen

/png  (transparent background unless noted)
  mendozer-icon-*.png          - icon only, sizes 16 to 1024px
  mendozer-logo-full-*w.png    - full lockup, widths 400 to 2048px
  *-white-bg.png                - flattened white-background versions for
                                   print/contexts that don't support transparency

/webp
  Web-optimized versions of the most-used sizes for faster page loads

USAGE NOTES
- Use SVG wherever possible (navbar, favicon source, print) for pixel-perfect scaling.
- Use icon-only mark for favicon, app icon, small UI elements.
- Use full lockup for header/footer, business documents, letterhead.
- Gradient: #1CABF1 -> #1E4FC7 (light cyan-blue to deep blue)
- Wordmark navy: #1C4E89 | "INVESTMENTS" light blue: #2FA1DB
